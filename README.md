# Fast L1-Regularized QSM with Magnitude Weighting and SHARP Background Filtering

MATLAB code and example in vivo 3D GRE data (0.6 mm) for fast QSM with closed-form L2 and Split-Bregman L1 regularization, with Laplacian phase unwrapping and SHARP background filtering.

- `script_Laplacian_unwrap_Sharp_Fast_TV_gre3D.m`: closed-form L2-regularized and Split-Bregman L1-regularized QSM
- `script_Laplacian_unwrap_Sharp_Magnitude_TV_gre3D.m`: magnitude-weighted L2- and L1-regularized QSM

## Usage

Run either script from the repository folder in MATLAB.
